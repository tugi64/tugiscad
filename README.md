# TugisCAD

Android tabanlı CAD (Computer-Aided Design) uygulaması.

## Geliştirme

### Gereksinimler
- Android Studio (son sürüm önerilir)
- JDK 11 veya üzeri
- Android SDK (API Level 24+)

### Kurulum
1. Projeyi klonlayın
```bash
git clone git@github.com:tugi64/tugiscad.git
```

2. Android Studio ile açın
3. Gradle sync işlemini tamamlayın
4. Uygulamayı çalıştırın
